## Topik Aplikasi
Aplikasi Android sederhana untuk mengelola katalog nama teman mahasiswa.  
Aplikasi memiliki fitur:
- Menampilkan daftar nama mahasiswa
- Pencarian data (Searching)
- Pengurutan data (Sorting)
- Navigasi antar halaman
- Validasi input
- Tampilan Portrait & Landscape
- Logcat Android Studio
